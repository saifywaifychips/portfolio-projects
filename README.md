# Project 1: Password Strength Checker (Python)

## 🛡️ Why it matters
In cybersecurity, enforcing strong password policies is the first line of defense. I built this tool to show how i can code a simple password checker

## 🛠️ Features
- **Length Validation:** Ensures the password is at least 8 characters.
- **Digit Check:** Uses the `any()` function to verify at least one number is present.
- **Special Character Detection:** Uses `isalnum()` logic to find symbols like !, @, or #.

## 🚀 How to run
1. Ensure Python 3.13+ is installed.
2. Run the script: `python password_check.py`
3. Enter a password when prompted.

## 🧠 What I learned
I learned how to use string methods in Python to parse user input. Specifically, I mastered the `any()` function and learned how indentation in Python acts as a "container" for function logic.
